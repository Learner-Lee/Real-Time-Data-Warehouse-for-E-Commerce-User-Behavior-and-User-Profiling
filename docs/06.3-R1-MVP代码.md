## 校验中发现并修复的问题

| 问题 | 怎么发现的 | 处理 |
|---|---|---|
| HBase 连接器需要 Hadoop 的类（`NoClassDefFoundError: Writable`），虚拟机上冒烟测试第 3 项和 DWD 作业都会失败 | SQL 规划校验 | `05-flink.sh` 加上 hadoop-client-api / runtime 3.3.6 |
| MySQL CDC 连接器生成执行计划时就要加载驱动 | SQL 规划校验 | 虚拟机上已经有；测试里补上同版本的驱动 |
| Doris 连接器生成执行计划时要连 FE | SQL 规划校验 | 测试里换成 blackhole；Doris 的参数由冒烟测试验证 |
| `DeliveryGuarantee` 不在 Kafka 连接器的 jar 里 | 编译 | 加 flink-connector-base（provided，运行时由 Flink 提供） |
| 测试类路径上 Jackson 版本混用 | 单元测试 | 用 jackson-bom 统一版本 |
| 迟到 120 秒的数据不一定超过允许迟到时间 | 推算 Watermark | 默认改成 180 秒 |
| 回放结束后，最后的窗口不会触发 | 推算 Watermark | 对账查询排除最后 3 分钟 |
| 4 个作业需要的 slot 超过 4 个 | 推算资源 | 并行度都设为 1 |

## 关键决策

| 决策 | 理由 |
|---|---|
| 迟到数据用 Java DataStream 处理，主链路用 Flink SQL | 纯 SQL 做不到侧输出；对账时能直接看出两者的差异 |
| UV 用 Doris 的 BITMAP 聚合表 | 跨任意时间段都能精确去重，重复导入也不会多算 |
| HBase rowkey 用能算出来的盐值，加预分区 | 打散写热点，同时不影响点查 |
| 交易指标用普通 GROUP BY + Unique 模型 | CDC 变更流里的退款会撤回已算的结果 |
| 同时用 Flink sink 和 Routine Load 写 Doris | 两种导入方式都练到 |
| 加模拟数据生成器和回放器演练模式 | 还没下载真实数据、没装好环境时，也能跑通和检查 |

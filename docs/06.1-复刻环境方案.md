## 结论

复刻环境定为：VMware Fusion（已装 25.0.0）里的 Ubuntu Server 24.04 ARM64 虚拟机，不装桌面，组件原生安装，单节点部署。虚拟机规格为 6 核、16GB 内存、80GB 动态磁盘。

## 依据

- **你的选择**：用 VMware 里的 Ubuntu 24 服务器版，不装桌面，节约空间。
- **机器情况**：
  - Apple M5、32GB 内存、10 核；
  - 磁盘剩余 38GB；
  - Docker Desktop 占了 38GB；
  - 还没有建过虚拟机。

## 关键决策

| 决策 | 理由 |
|---|---|
| 用 ARM64 镜像 | Apple 芯片上的 VMware 只能跑 ARM64 系统 |
| 组件原生安装，不套 Docker | 亲手部署、亲手调配置，面试被问部署时有真实经验 |
| 安装 Ubuntu 时取消 LVM | 默认的 LVM 方案只给根分区分一半空间 |
| 关 swap、调 `vm.max_map_count` 和文件句柄数，并给 Doris 设内存上限 | Doris 的硬性要求；它默认会占用 90% 的内存 |
| 安装选 OpenSSH，从 Mac 用专用密钥免密登录 | 两种协作方式都需要；我不能替你输入密码 |
| 建议你清理 Docker Desktop 的数据（由你决定和操作） | 可以腾出 38GB；Mac 的磁盘是后续复刻的主要瓶颈 |

## 关键决策

| 决策 | 理由 |
|---|---|
| Kafka 用 4.3.2，不用 3.9 | 3.9 只剩归档站有、国内镜像没有；4.x 已彻底去掉 ZooKeeper |
| Doris 用 4.0.8 | 4.0 系列已出 8 个补丁版本，比较稳定，还带向量检索和 AI 函数 |
| HBase 连接器用 4.0.0-1.19 | 官方没有适配 1.20 的版本；由冒烟测试验证，不行就整套降到 Flink 1.19 |
| Flink 配置用 PyYAML 修改，不整体覆盖 | 保留默认配置里 Java 17 必需的启动参数 |
| 密码由你在 r1.env 里自己设 | 不由我生成；没改就拒绝运行 |
| 下载先走国内镜像，失败自动换官方地址 | 兼顾速度和可靠性 |
